# WakeBridge design

Mode: Operate. Product brief and first delivery were approved before implementation. No existing visual authority.

Grounded references considered: home router status, desktop device manager, home automation room list, address book, OS network preferences, household switchboard, equipment label directory. The assigned sixth direction is the household switchboard: stable device rows, a clear connection indicator, local-first language, actions placed at the device. It carries the simple daily task better than the offered split-flap, acetate manual or monumental type references; those reduce device-state readability on a phone. No decorative topology claims.

Light surface for daytime phone use; system dark mode for evenings. Warm off-white canvas, forest green controls, charcoal text, restrained ruled rows. Self-hosted Manrope variable font. Spacious overview with device rows and an adjacent connection guide; narrow screens put guidance below the inventory. Actual MAC/IP data is monospace, ordinary UI is proportional. Presence is always a label plus an indicator, never color alone. Offline copy explains uncertainty. Onboarding is an inline flow rather than an interrupting modal. Only revocation requires an alert dialog.

First viewport: workspace selector, devices heading, search, add-device action, live inventory or a helpful real empty state. Working status and recent activity remain visible. No fabricated metrics or devices. Keyboard navigation, 44px touch targets, reduced motion and full error/loading/empty states are required.
